# Marstoy → LEGO Finder

Live site: https://codzbeast.github.io/marstoy-lego/

Every kit in Marstoy's [Brick Kits](https://marstoy.com/collections/brick-kits) collection (354 items) matched to the real LEGO set, with a picture and direct links to both stores.

The Marstoy SKU is the LEGO set number with its digits reversed: `M63224` → `42236`.

- 334 sets link straight to their LEGO.com product page.
- 20 retired sets aren't on LEGO.com anymore, so their LEGO button opens Brickset instead.
- `marstoy_to_lego.csv` has the full table (set name, Marstoy link, LEGO link, SKU, set number, status).

Set images come from Brickset. Not affiliated with LEGO or Marstoy.
